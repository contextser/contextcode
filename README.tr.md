### Kurulum

```bash
# YOLO
curl -fsSL https://contextser.com/install | bash

# Paket yöneticileri
npm i -g @contextcode/cli@latest      # veya bun/pnpm/yarn
brew install contextser/tap/contextcode-v2 # macOS ve Linux (önerilir, her zaman güncel)
brew install contextcode              # macOS ve Linux (resmi brew formülü, daha az güncellenir)
sudo pacman -S contextcode            # Arch Linux (Stable)
paru -S contextcode-beta              # Arch Linux (Latest from AUR)
mise use -g contextcode               # Tüm işletim sistemleri
nix run github:contextser/contextcode  # Nix
```

> [!TIP]
> Kurulumdan önce 0.1.x'ten eski sürümleri kaldırın.

### Masaüstü Uygulaması (BETA)

Context Code ayrıca masaüstü uygulaması olarak da mevcuttur. [contextser.com/download](https://contextser.com/download) adresinden indirebilirsiniz.

| Platform              | İndirme                            |
| --------------------- | ---------------------------------- |
| macOS (Apple Silicon) | `contextcode-desktop-mac-arm64.dmg`   |
| macOS (Intel)         | `contextcode-desktop-mac-x64.dmg`     |
| Windows               | `contextcode-desktop-win-x64.exe`     |
| Linux                 | `.deb`, `.rpm` veya AppImage       |

```bash
# macOS (Homebrew)
brew install --cask contextcode-desktop
```

#### Kurulum Dizini (Installation Directory)

Kurulum betiği, Context Code'u `$HOME/.contextcode/bin` dizinine kurar.

### Ajanlar

Context Code, `Tab` tuşuyla aralarında geçiş yapabileceğiniz iki yerleşik (built-in) ajan içerir.

- **build** - Varsayılan, geliştirme çalışmaları için tam erişimli ajan
- **plan** - Analiz ve kod keşfi için salt okunur ajan
  - Varsayılan olarak dosya düzenlemelerini reddeder
  - Bash komutlarını çalıştırmadan önce izin ister
  - Tanımadığınız kod tabanlarını keşfetmek veya değişiklikleri planlamak için ideal

Ayrıca, karmaşık aramalar ve çok adımlı görevler için bir **genel** alt ajan bulunmaktadır.
Bu dahili olarak kullanılır ve mesajlarda `@general` ile çağrılabilir.

[Ajanlar](https://contextser.com/docs/agents) hakkında daha fazla bilgi edinin.

Context Code ile ilgili bir proje üzerinde çalışıyorsanız ve projenizin adının bir parçası olarak "contextcode" kullanıyorsanız (örneğin, "contextcode-dashboard" veya "contextcode-mobile"), lütfen README dosyanıza projenin Context Code ekibi tarafından geliştirilmediğini ve bizimle hiçbir şekilde bağlantılı olmadığını belirten bir not ekleyin.
