title: "Commands"
description: "Reference for the contextcode command line."
---

Every command accepts `--help` for its full flag list, for example `contextcode run --help`. Some server-backed commands accept `--standalone` to run a private server or `--server <url>` to target a specific one; check the command's help for its supported flags.

## run

Sends a message and prints the reply without opening the interactive interface.

```bash
$ contextcode run "Explain this repository"
```

### CI

In CI, pass a provider API key as a secret and use standalone mode so the private server receives it. For example, this GitHub Actions job reviews the checked-out repository:

```yaml
name: Context Code review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @contextcode/cli
      - run: contextcode run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Choose a model.

```bash
$ contextcode run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Continue the last session.

```bash
$ contextcode run --continue "Now handle the expired case"
```

Emit newline-delimited JSON for scripts.

```bash
$ contextcode run --format json "List the TODO comments"
```

Attach files to the message.

```bash
$ contextcode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Run with a specific agent.

```bash
$ contextcode run --agent build "Fix the failing test"
```

Continue a specific session.

```bash
$ contextcode run --session ses_4f2a1c "Check edge cases"
```

Auto-approve permissions that are not explicitly denied.

```bash
$ contextcode run --auto "Fix the failing test"
```

View all subcommands and flags.

```bash
$ contextcode run --help
```

## mini

Starts the minimal interactive interface instead of the full-screen TUI.

```bash
$ contextcode mini
```

Continue the last session.

```bash
$ contextcode mini --continue
```

Start with a model and an initial prompt.

```bash
$ contextcode mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Continue a specific session.

```bash
$ contextcode mini --session ses_4f2a1c
```

View all subcommands and flags.

```bash
$ contextcode mini --help
```

## session

Manages sessions.

```bash
$ contextcode session list
```

Limit the list and print JSON.

```bash
$ contextcode session list --max-count 20 --format json
```

Delete a session and its child sessions.

```bash
$ contextcode session delete ses_9c1b08
```

Export session data as JSON.

```bash
$ contextcode session export ses_4f2a1c
```

Redact sensitive transcript and file data when exporting.

```bash
$ contextcode session export ses_4f2a1c --sanitize
```

Import session data from a JSON file or URL.

```bash
$ contextcode session import session.json
```

Import into a specific directory.

```bash
$ contextcode session import session.json --directory ~/code/project
```

View all subcommands and flags.

```bash
$ contextcode session --help
```

## auth

Manages AI providers and credentials.

```bash
$ contextcode auth list
```

List them as JSON.

```bash
$ contextcode auth list --format json
```

Log in to a provider.

```bash
$ contextcode auth login anthropic
```

Log in with a specific authentication method.

```bash
$ contextcode auth login anthropic --method key
```

Log out of a saved account.

```bash
$ contextcode auth logout anthropic work
```

Switch the active account for an integration.

```bash
$ contextcode auth switch anthropic work
```

Export saved credentials and import them on another machine. The file contains secrets.

```bash
$ contextcode auth export anthropic > credentials.json
$ contextcode auth import credentials.json
```

View all subcommands and flags.

```bash
$ contextcode auth --help
```

## mcp

Manages MCP (Model Context Protocol) servers.

```bash
$ contextcode mcp list
```

Add a remote server.

```bash
$ contextcode mcp add context7 --url https://mcp.context7.com/mcp
```

Add a local server to the global config.

```bash
$ contextcode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Add a local server with an environment variable.

```bash
$ contextcode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Add a remote server with a header.

```bash
$ contextcode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Authenticate with an OAuth-capable remote server.

```bash
$ contextcode mcp auth sentry
```

Remove stored OAuth credentials for a server.

```bash
$ contextcode mcp logout sentry
```

View all subcommands and flags.

```bash
$ contextcode mcp --help
```

## serve

Starts the API and web server. See [Web](/cli/web).

```bash
$ contextcode serve
```

Bind to all interfaces on a fixed port.

```bash
$ contextcode serve --hostname 0.0.0.0 --port 4096
```

Allow a browser client from another origin.

```bash
$ contextcode serve --cors https://app.example.com
```

View all subcommands and flags.

```bash
$ contextcode serve --help
```

## pair

Prints one-time links, plus a QR code of the first one, that sign a browser or
app in to the server. Links expire after 5 minutes and work once.

```bash
$ contextcode pair
```

Use an external URL in the links.

```bash
$ contextcode pair --url https://dev.example.com
```

Pair from anywhere through an OpenTunnel remote address. This exposes the
server to the internet, so the first time it enables remote access it explains
this and asks you to accept. See [Remote access](/cli/web#remote-access).

```bash
$ contextcode pair --remote
```

Accept without a prompt, for example in a script without a terminal.

```bash
$ contextcode pair --remote --yes
```

View all subcommands and flags.

```bash
$ contextcode pair --help
```

## service

Manages the background server. See [Web](/cli/web).

```bash
$ contextcode service start
```

Restart it.

```bash
$ contextcode service restart
```

Show its status.

```bash
$ contextcode service status
```

Stop it.

```bash
$ contextcode service stop
```

Read a setting.

```bash
$ contextcode service get hostname
```

Set a setting.

```bash
$ contextcode service set hostname 0.0.0.0
```

Allow an extra CORS origin.

```bash
$ contextcode service set cors https://app.example.com
```

Pass an environment variable to the server process.

```bash
$ contextcode service set env CONTEXTCODE_LOG_LEVEL DEBUG
```

Reset a setting to its default.

```bash
$ contextcode service unset hostname
```

View all subcommands and flags.

```bash
$ contextcode service --help
```

## reload

Reloads configuration without restarting the server. Running sessions continue with fresh services at the next step boundary.

```bash
$ contextcode reload
```

## api

Makes a request to the running server.

```bash
$ contextcode api GET /api/session
```

Call an operation ID with a query parameter.

```bash
$ contextcode api session.list --param limit=10
```

Send a JSON body.

```bash
$ contextcode api session.create --data '{"title": "New session"}'
```

Add a request header.

```bash
$ contextcode api GET /api/session -H "accept: application/json"
```

View all subcommands and flags.

```bash
$ contextcode api --help
```

## debug

Provides debugging and troubleshooting tools.

```bash
$ contextcode debug agents
```

List configuration sources.

```bash
$ contextcode debug config
```

Write a heap snapshot of the running background server and print its path.

```bash
$ contextcode debug heap-dump
```

Write the snapshot into a directory of your choice.

```bash
$ contextcode debug heap-dump --directory ./snapshots
```

Show global paths.

```bash
$ contextcode debug paths
```

Print a single path.

```bash
$ contextcode debug paths db
```

View all subcommands and flags.

```bash
$ contextcode debug --help
```

## upgrade

Upgrades Context Code to the latest or a specific version. Alias: `update`.

```bash
$ contextcode upgrade
```

Upgrade to a specific version with a specific package manager.

```bash
$ contextcode upgrade 2.0.21 --method bun
```

View all subcommands and flags.

```bash
$ contextcode upgrade --help
```

## uninstall

Stops background services, removes the global cache, and uninstalls Context Code. Session data, configuration, and
state are not removed.

```bash
$ contextcode uninstall
```

Preview what would be removed.

```bash
$ contextcode uninstall --dry-run
```

View all subcommands and flags.

```bash
$ contextcode uninstall --help
```
