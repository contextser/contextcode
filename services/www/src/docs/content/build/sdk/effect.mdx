title: "Effect"
---

`@contextcode/sdk/effect` is the Effect-native embedded SDK. Operations return typed Effects and Streams, and closing
the owning Scope releases the router, Location services, fibers, and plugin registrations.

```sh
bun add @contextcode/sdk effect@4.0.1
```

## Create a host

Create the host inside `Effect.scoped`, then use its generated API groups or the `sessions` alias.

```ts
import { AbsolutePath, Location, ContextCode } from "@contextcode/sdk/effect"
import { Effect } from "effect"

const program = Effect.scoped(
  Effect.gen(function* () {
    const contextcode = yield* ContextCode.create()
    const session = yield* contextcode.sessions.create({
      location: Location.Ref.make({ directory: AbsolutePath.make("/workspace") }),
    })
    yield* contextcode.sessions.prompt({
      sessionID: session.id,
      text: "Review the current changes",
    })
    return session
  }),
)

const session = await Effect.runPromise(program)
```

The embedded host uses the same schema values, declared errors, request options, and Streams as
`@contextcode/client/effect`.

```ts
const info = yield* contextcode.server.info()
const sessions = yield* contextcode.sessions.list()
```

## Stream events

Streaming endpoints return Effect `Stream` values. Fork consumers in the host Scope when they should run in the
background.

```ts
import { Effect, Stream } from "effect"

yield* contextcode.events.subscribe().pipe(
  Stream.runForEach((event) => Effect.logInfo("Context Code event", { type: event.type })),
  Effect.forkScoped,
)
```

## Customize

Customize your Context Code instance by registering Effect plugins. Use the embedded
host to customize agents, models, tools, and other behavior:

```ts
import { Plugin } from "@contextcode/plugin/effect"
import { Effect } from "effect"

const plugin = Plugin.define({
  id: "customize-agent",
  effect: (ctx) =>
    Effect.gen(function* () {
      const agent = ctx.agent
      yield* agent.transform((agents) => {
        agents.update("build", (agent) => {
          agent.description = "Builds features and fixes bugs for our team"
        })
      })
    }),
})

yield* contextcode.plugin(plugin)
```

See the [full Effect plugins documentation](/build/plugins/effect) for plugin
hooks, transforms, tools, and the complete plugin context.

## Layer

Use `ContextCode.layer()` when the embedded host should be an application service.

```ts
import { ContextCode } from "@contextcode/sdk/effect"
import { Effect } from "effect"

const program = Effect.gen(function* () {
  const contextcode = yield* ContextCode.Service
  return yield* contextcode.server.info()
})

const health = await Effect.runPromise(program.pipe(Effect.provide(ContextCode.layer())))
```
