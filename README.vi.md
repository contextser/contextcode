### Cài đặt

```bash
# YOLO
curl -fsSL https://contextser.com/install | bash

# Các trình quản lý gói (Package managers)
npm i -g @contextcode/cli@latest      # hoặc bun/pnpm/yarn
brew install contextser/tap/contextcode-v2 # macOS và Linux (khuyên dùng, luôn cập nhật)
brew install contextcode              # macOS và Linux (công thức brew chính thức, ít cập nhật hơn)
sudo pacman -S contextcode            # Arch Linux (Bản ổn định)
paru -S contextcode-beta              # Arch Linux (Bản mới nhất từ AUR)
mise use -g contextcode               # Mọi hệ điều hành
nix run github:contextser/contextcode  # Nix
```

> [!TIP]
> Hãy xóa các phiên bản cũ hơn 0.1.x trước khi cài đặt.

### Ứng dụng Desktop (BETA)

Context Code cũng có sẵn dưới dạng ứng dụng desktop. Tải từ [contextser.com/download](https://contextser.com/download).

| Nền tảng              | Tải xuống                          |
| --------------------- | ---------------------------------- |
| macOS (Apple Silicon) | `contextcode-desktop-mac-arm64.dmg`   |
| macOS (Intel)         | `contextcode-desktop-mac-x64.dmg`     |
| Windows               | `contextcode-desktop-win-x64.exe`     |
| Linux                 | `.deb`, `.rpm`, hoặc AppImage      |

```bash
# macOS (Homebrew)
brew install --cask contextcode-desktop
```

#### Thư mục cài đặt

Tập lệnh cài đặt sẽ cài Context Code vào `$HOME/.contextcode/bin`.

### Agents (Đại diện)

Context Code bao gồm hai agent được tích hợp sẵn mà bạn có thể chuyển đổi bằng phím `Tab`.

- **build** - Agent mặc định, có toàn quyền truy cập cho công việc lập trình
- **plan** - Agent chỉ đọc dùng để phân tích và khám phá mã nguồn
  - Mặc định từ chối việc chỉnh sửa tệp
  - Hỏi quyền trước khi chạy các lệnh bash
  - Lý tưởng để khám phá các codebase lạ hoặc lên kế hoạch thay đổi

Ngoài ra còn có một subagent **general** dùng cho các tìm kiếm phức tạp và tác vụ nhiều bước.
Agent này được sử dụng nội bộ và có thể gọi bằng cách dùng `@general` trong tin nhắn.

Tìm hiểu thêm về [agents](https://contextser.com/docs/agents).

Nếu bạn đang làm việc trên một dự án liên quan đến Context Code và sử dụng "contextcode" như một phần của tên dự án, ví dụ "contextcode-dashboard" hoặc "contextcode-mobile", vui lòng thêm một ghi chú vào README của bạn để làm rõ rằng dự án đó không được xây dựng bởi đội ngũ Context Code và không liên kết với chúng tôi dưới bất kỳ hình thức nào.
